Install from the shell

The shell installer installs the stable release. An installed nightly stays on its channel when you run the shell installer again. On macOS it checks the download's Developer ID signature (FastAF's team, NH9933XQGX) in a private temporary folder before it replaces the app; if any check fails, nothing is installed.

Channels

The buttons above give the newest stable release. To install the nightly from the shell on macOS or Linux, pass the channel name:

curl -fsSL https://raw.githubusercontent.com/ksg98/fastaf-ide/main/website/public/install.sh | sh -s nightly

The nightly build follows main. In the app, Settings → General → Update Channel (Expert) selects Stable or Nightly for updates. FastAF publishes no beta channel.

System requirements

  • macOS 12 Monterey or later. Mermaid diagrams need the system WebKit of Safari 17.4 or later.
  • Windows 64-bit with the WebView2 runtime.
  • Linux x86_64 with WebKitGTK.

The tuic-remote daemon (beta) has its own binaries for Linux, macOS and Windows on each release page.
