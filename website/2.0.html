Release · 2.0

FastAF 2.0. One day, ten projects.

The film follows one person through one working day: ten projects, dozens of agents, one orchestrator. Everything in it is the real 2.0 interface.

The film's project data is fictional. The interface is not.

What changed, area by area

The biggest release since the first one. Each area has its own page.

Orchestrate agents

Rich sidebar cards, the + agent menu, CLI | Chat for Claude, Codex, Grok and ego, agents that spawn and message agents, Progress List and Flow, AI Chat on FastAF's built-in engine.

Plan the work

Native plans and stories with criteria, dependencies, revisions and a Kanban board; the Workflow designer; automations with templates, Run now and history.

Review and ship

Tasks for work items from a provider plugin you install; pull request line review threads; CI auto-heal for GitHub Actions and CircleCI; multiple GitHub accounts.

Workspace

Markdown panel with inline review comments, Design Mode, settings search, light themes, suspendable tabs.

Anywhere

Mobile Chat view and question cards with push, remote machines over SSH with tuic-remote, hands-free voice and spoken replies.

Extend

MCP Proxy Hub with secret headers and tool filters, private secret forms for agents, the fastaf CLI and plugins installed from a folder or ZIP file.

Shipped, not filmed

Quiet changes that matter on a long day.

Resume after an update

After an update restart, every agent tab with a confirmed session resumes on its own. The restart waits until no agent is busy or waiting for you.

Hibernation

Idle agent tabs that can resume are hibernated after a time you choose, and wake on open, input or mail.

Tray and menu bar

A tray icon with live agent counts and an attention indicator. Choose always, only in background, or never.

Native scrollback

Claude, Codex, Grok and supported OpenCode versions start without alternate-screen rendering, so the terminal keeps their full history.

Windows, tested

The test suite now builds and runs on Windows in CI, so Windows stays working.

Private secret forms

An agent asks for a password or a one-time code; you type it into a separate window, and the agent never sees the value.

Upgrading from 1.7

  • Updates install as before. Settings → General → Updates has two new switches, both on by default: resume all agents after an update, and wait for agents before restarting.
  • FastAF ships no Tasks provider plugin. Tasks appears once you install one from a folder or a ZIP file; configure its accounts in Tasks, not in a plugin settings page.
  • AI Chat keeps running on FastAF's built-in engine. Sign in with ChatGPT or add a provider in Settings → Providers, then turn on Experimental Features and its AI Chat sub-toggle; no external agent is needed.

Every change is in the changelog.
